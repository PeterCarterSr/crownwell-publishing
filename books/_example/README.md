# Example Book Template

This directory serves as a template for new book projects.

To create a new book:
1. Copy this directory: cp -r books/_example books/your-book-name
2. Add your DOCX to input/original.docx
3. Add your cover image as cover.jpg (optional)
4. Edit metadata.yaml with book details
5. Run: python tools/build-epub.py books/your-book-name
